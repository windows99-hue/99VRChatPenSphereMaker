# 99 VRChat Pen Sphere Maker

> 画个球给自己圈了起来，隔绝所有伤害

## 安装

本程序支持`python3`，你可以运行如下代码安装所需要的库

~~~cmd
pip install -r requirements.txt
~~~

## 使用

**使用PC端**在vrchat中拿起笔并将视角抬升到最高，运行程序，在**3秒内**切回到vrchat游戏视图中并使你的鼠标输入到你的vrchat中（就是回到游戏里点一下），之后程序会自动画出球，请在你认为合适的地方按下q键结束程序

## 设置

请按需求调整程序第28 31 33行的除了0以外的数字

第33行为程序画完一圈后向下移动的距离，控制球体线的疏密

第28和31行共同确认程序能否画出一个完整的圆
